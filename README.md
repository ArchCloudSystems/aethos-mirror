# Aethos Mirror

Aethos Mirror is a standalone Electron kiosk/browser appliance for the AetherCore/Aethos ecosystem.

It is inspired by MagicMirror, but its purpose is different: it is an assistant-operated display and real Chromium browser cockpit for CAILEAN and EILIDH/Ailee.

AetherCore remains the Mothership brain/control plane.
Aethos Mirror is the display, browser, overlay, and assistant presence surface.
